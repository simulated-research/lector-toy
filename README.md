# Forty-Eight Small Worlds

A toy: a live field catalogue of 48 procedurally generated small worlds. Each
world is deterministic from its catalogue number — same number, same world,
every time — with its own terrain, atmosphere, clouds, moons, and dossier of
(invented but internally consistent) astrometric readings.

- Drag the planet to spin it.
- Use the arrows or ← → keys to page through the catalogue.
- "Wander" jumps to a random world.

Single self-contained `index.html`. No build step, no dependencies beyond two
web fonts. Open it in a browser.

Part of a public exhibition of randomly created AI toys.
